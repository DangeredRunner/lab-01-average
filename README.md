#Average of 3 numbers calculator

##Problem 
I needed to calculate the mathematical average of three separate numerical inputs.

##What I built
A C program that prompts the user for three numbers, adds them up, and divides the total by three.

##How it works
Enter the first, second, and third numbers.
Add the numbers together.
Divide the sum by 3 to get the average.
Output the final result.

##How I tested it
I used three numbers: 10, 20, and 30.
The output was 20.

##What I learned
Calculating an average requires aggregating all items completely before applying the division step, and keeping track of data types (floats vs. integers) ensures accurate division.

##Limitations
The program only works for exactly three numbers and cannot accept a dynamic or variable amount of inputs.
